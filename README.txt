
── ■ │ WHAT IS NFSMW ANTAGONIST? (v1.00.00) │ ■ ───────────────────────────────────────────────────

VIEW THIS FILE on GitHub: https://github.com/rng-guy/NFSMWAntagoNISt

AntagoNISt lets you change BACKGROUND VEHICLES in NIS cutscenes that have any.

The SECTIONS BELOW address these questions in detail:
 1) • How do I install AntagoNISt for my game?
 2) • Which mods are (in)compatible with AntagoNISt?
 3) • How may I share or bundle AntagoNISt?
 4) • What changed in each version of AntagoNISt?






── ■ │ 1 - HOW DO I INSTALL ANTAGONIST FOR MY GAME? │ ■ ───────────────────────────────────────────

BEFORE INSTALLING AntagoNISt:
 1) • make sure your original copy of the game isn't a repack or came pre-modified in any way,
 2) • read and understand the section about mod (in)compatibilities below,
 3) • make sure your game's "speed.exe" is compatible (i.e. 5.75 MB / 6,029,312 bytes large), and
 4) • install an .asi loader or any mod with one (e.g. the "WideScreenFix" mod by ThirteenAG).

TO INSTALL AntagoNISt:
 1) • copy AntagoNISt's "scripts" folder to your game's folder, replacing existing files; and
 2) • if AntagoNISt's .asi file gets flagged by your antivirus software, whitelist the file.

AFTER INSTALLING AntagoNISt, edit its "NFSMWAntagoNIStSettings.ini" file to your liking.

TO UNINSTALL AntagoNISt, remove its files from your game's "scripts" folder.

TO UPDATE AntagoNISt, uninstall it and repeat the installation process above.






── ■ │ 2 - WHICH MODS ARE (IN)COMPATIBLE WITH ANTAGONIST? │ ■ ─────────────────────────────────────

All VLTED AND BINARY MODS should be fully compatible with AntagoNISt.

Almost all OTHER .ASI MODS should be fully compatible with AntagoNISt.






── ■ │ 3 - HOW MAY I SHARE OR BUNDLE ANTAGONIST? │ ■ ──────────────────────────────────────────────

You are free to bundle AntagoNISt and its files with your own mod, NO CREDIT REQUIRED. 
In the interest of code transparency, however, consider linking to AntagoNISt's GitHub repository
(https://github.com/rng-guy/NFSMWAntagoNISt) somewhere in your mod's documentation (e.g. README).
